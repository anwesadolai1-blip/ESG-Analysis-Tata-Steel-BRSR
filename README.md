# ESG Performance Analysis of Tata Steel (FY2023–24 to FY2025–26)

## Overview
This project analyzes Tata Steel's Business Responsibility and Sustainability Reports (BRSRs) from FY2023–24 to FY2025–26. The objective was to understand trends in environmental performance using publicly available ESG disclosures.

## Objectives
- Extract environmental KPIs from BRSRs
- Organize ESG data in Excel
- Analyze trends using Python
- Visualize sustainability metrics

## Tools Used
- Python
- Pandas
- Matplotlib
- Microsoft Excel
- Google Colab

## KPIs Analyzed
- Scope 1 Emissions
- Scope 2 Emissions
- Emission Intensity
- Total Water Withdrawal
- Total Water Consumption
- Water Intensity
- Total Energy Consumed

## Data Source
Business Responsibility and Sustainability Reports (BRSRs) published by Tata Steel.
